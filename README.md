# Aplikasi Kasir Kukuh Laundry

Program berbasis Command Line Interface (CLI) menggunakan bahasa Go (Golang) untuk menghitung total biaya jasa laundry dengan layanan antar serta menghitung kembalian pembayaran pelanggan.

## Fitur-Fitur Program
- *Input Data Transaksi*: Menerima input berat cucian (kg) dan nominal uang pembayaran dari pelanggan.
- *Perhitungan Biaya Otomatis*: Menghitung biaya cucian (Rp 9.500/kg) ditambah biaya layanan antar (Rp 3.000).
- *Validasi Pembayaran & Kembalian*: Menampilkan nominal kembalian jika uang cukup atau informasi kekurangan pembayaran.

## Teknologi yang Digunakan
- *Bahasa Pemrograman*: Go (Golang)
- *Standard Library*: fmt
- *Version Control*: Git & GitHub

## Cara Menjalankan Program
1. Pastikan Go (Golang) sudah terinstal di perangkat Anda.
2. Clone repository ini ke komputer lokal:
   bash
   git clone <url-repository-github-anda>
   
3. Masuk ke direktori proyek:
   bash
   cd tugasddp
   
4. Jalankan program:
   bash
   go run tgs.go
